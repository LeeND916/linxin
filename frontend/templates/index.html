    • 
                            
  • 任务专属成就（achievement_id 含 mission）→ 删除
    • 
                            
  • 任务生成的社交关系（friend 中 mission_id 非空）→ 删除
    • 
                            
  • 游戏时间、天气、穿搭历史 → 重置为初始值
    • 
                            
  • 玩家关系四指标 → 重置为陌生人（Tier 0）
    • 
                            
  • 恋爱关系 → 重置为普通朋友
    • 
                            
  • 地点访问次数 → 重置为 0
    • 
                            
  • 朋友互动记录 → 清空（保留好友列表和好感度）
    • 
                            
  • 基础属性（能量、情绪、压力、健康等）→ 重置为角色初始基线值（baselines）
    • 
                            
  • 技能（skill_*）→ 重置为角色初始值
    • 
                            
  • 当前穿搭（current_outfit）→ 清空
    • 
                            
  • 情绪历史 → 清空
    • 
                            
  • 待处理任务标记、当日计划地点 → 清空
    • 
                            
  • 心理状态初始化标记（mental_initialized）→ 重置，下次对话重新建立心理画像
    • 
                            
  • 主动消息冷却计数 → 重置
