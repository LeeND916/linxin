## 🚀 快速开始

**三步进游戏：**

1. 双击根目录的 **`启动游戏.bat`**
2. 浏览器自动打开 <http://127.0.0.1:5080>（没自动打开就手动访问）
3. 进游戏后点 **设置（齿轮）**，按下面清单配好就能玩

> 打包版已内置独立 Python 运行时（`runtime/`），**目标机不需要装 Python、不需要联网、不需要 VC++ 运行库**，整个文件夹拷过去双击即用。

### ⚙️ 第一次启动要做的人工配置

点开 **设置** 会看到 9 个页签。**只有「大模型」是必填**，其余都是可选增强——不配也能聊天，只是对应功能不生效。

| 想要的功能          | 去哪个页签         | 必填？      |
| -------------- | ------------- | -------- |
| 和她聊天（核心）       | **大模型**       | **必填**   |
| 长期记忆 / 笔记的语义召回 | **Embedding** | **强烈建议** |
| 情感分析（对话情绪属性）   | 小模型           | 可选       |
| 语音生成（让她出声）     | 语音            | 可选       |
| 聊天生图 / 肖像      | ComfyUI       | 可选       |
| 她能看懂你发的图       | 视觉回看          | 可选       |
| 外部笔记同步         | Memos         | 可选       |
| 新闻、提示词         | 资讯 / 提示词      | 一般不用动    |

---

#### 1️⃣ 聊天大模型（必填）

**设置 → 大模型 → 新增配置**

| 字段          | 怎么填                                                                              |
| ----------- | -------------------------------------------------------------------------------- |
| 平台          | 选你的服务商；本地跑选 LLM Studio / Ollama；找不到对应项就选 `Custom (OpenAI Compatible)`            |
| API URL     | **完整端点**，要带 `/chat/completions`。例：`https://api.deepseek.com/v1/chat/completions` |
| API Key     | 你的密钥                                                                             |
| Model Name  | 例：`deepseek-chat` / `gpt-4o-mini` / `qwen2.5:7b`                                 |
| Temperature | 保持默认 `0.85`                                                                      |
| Max Tokens  | 默认 `4000`。**角色设定越复杂越容易撞上限**——生成大批量内容（穿搭、发型、任务）时建议调到 `8000`                       |

填完 → **测试连接** → **保存** → 回到「配置列表」点该条的 **激活**，出现「激活」徽标才算生效。

> ⚠️ **只保存不激活 = 没配**，这是最容易漏的一步。未激活时页面显示「模拟模式」，无法正常对话。  
> 任何 OpenAI 兼容接口都行：DeepSeek / 通义千问 / OpenAI / 智谱 / SiliconFlow / 本地 llama.cpp、LM Studio、Ollama……

---

#### 2️⃣ 长期记忆 & 笔记的 Embedding（强烈建议）

**设置 → Embedding → 新增配置**

| 字段      | 怎么填                                                                            |
| ------- | ------------------------------------------------------------------------------ |
| 平台      | 本地服务选 LLM Studio / Ollama；云端选 OpenAI / DashScope / 智谱 / SiliconFlow；其他选 Custom |
| API URL | **完整端点**，要带 `/embeddings`。例：`http://127.0.0.1:10039/v1/embeddings`             |
| API Key | 留空表示免认证                                                                        |
| 模型名称    | 例：`text-embedding-bge-m3`、`BAAI/bge-m3`                                        |
| 向量维度    | 与模型实际输出一致（bge-m3 为 `1024`，即默认值）                                                |

保存 → **激活**。



| 用到 Embedding 的地方              | 不配的后果                            |
| ----------------------------- | -------------------------------- |
| 长期记忆的语义召回（`character_memory`） | 记忆照样写入，但回忆时挑不中相关的那几条——**记了等于没记** |
| Memos 笔记的语义召回（`nerd_memo`）    | 同上                               |
| 意图分类、聊天里的「拍照」等图片意图识别          | 降级成关键词匹配，理解变差                    |





---

#### 3️⃣ 情感分析 → 设置 → 小模型

「小模型」是给轻量推理用的 OpenAI 兼容端点，承担两件事：

- **对话情绪属性分析** —— 从对话判断她的情绪与属性变化
- **TTS 语音参数分类** —— 生成腾讯云 TTS 需要的语气 / 语速 / 音量

填法：名称随意 → **访问地址填 API Base**（注意是 base，如 `http://127.0.0.1:10039/v1`，**不要带 `/chat/completions`**）→ 模型名（如 `qwen2.5-1.5b-instruct`）→ 保存 → **激活**。

> 首次启动会自动预置一条指向 `http://127.0.0.1:10039/v1` 的配置（来自 `local_config.py` 的 `SMALL_MODEL_URL`），地址不对直接改它。  
> 不配：情绪属性分析和 TTS 语气参数不生效，聊天照常。

---

#### 4️⃣ 语音生成 → 设置 → 语音

这里管的是**把台词真的合成成声音**，两种服务二选一：

| 服务类型                                                    | 要填什么                                            | 适合谁           |
| ------------------------------------------------------- | ----------------------------------------------- | ------------- |
| **腾讯云 TTS**                                             | SecretId + SecretKey                            | 不想自己部署，有腾讯云账号 |
| **VoiceDesign**（文字描述音色） / **Base**（上传样本克隆），自建 Qwen3-TTS | 服务地址（默认 `http://127.0.0.1:9802`）、API Token、模型路径 | 自己有显卡、想离线     |

保存后点 **激活**，再到「角色音色底色锚点」里给角色设音色（可文字描述音色，也可上传样本克隆）。

> 不配 TTS：没有语音，其余功能不受影响。

---

#### 5️⃣ 生图 ComfyUI（想让她发照片才配）

**设置 → ComfyUI**，两件事都要做：

1. **服务配置**：填 `ComfyUI API URL`（默认 `http://127.0.0.1:8188`，就是 ComfyUI 跑起来的那个地址），有鉴权再填 API Key → **测试连接** → 保存
2. **工作流配置**：上传一个 ComfyUI 工作流 JSON（在 ComfyUI 里用 **「导出（API格式）」** 得到），起个名，勾上 **「设为默认工作流」**

> 📌 仓库**不附带工作流 JSON**，必须自己导出。也可以把 JSON 放进 `data/comfyui/workflows/`，再点 **「扫描磁盘工作流」** 一键注册。  
> 不配 ComfyUI：聊天、记忆、剧情全部正常，只是不会生成图片。

---

#### 6️⃣ 其余页签（一般不用动）

- **视觉回看（VLM）**：她生成照片后由 VLM「回看」并写出描述。默认指向本地 LM Studio（`nsfwvision-qwen3-vl-8b-v3`）
- **Memos**：接你自己的 Memos 实例，把 memo 导入成角色的知识记忆
- **资讯**：内置新闻源，可直接用
- **提示词**：所有 prompt 都能在线改，改完即生效、不用重启

> 六类外部服务全部在网页里配置、测试、一键激活，改完即生效，不用改代码也不用重启。

## ✨ 特性

**🧠 她记得住**

- 长期记忆库：LLM 抽取 → 向量化 → 相似度召回注入对话
- 记忆带重要度衰减——你说过的重要事记一辈子，今天的外卖过几天就忘
- 高光时刻单独存档（表白 / 吵架 / 和解 / 梦想），**深夜或心情起伏时她会自己翻出来提**

**🕐 她在过自己的日子**

- 上课、健身、写作、逛街、旅行；熬夜会困，错过饭点会饿，两天不洗澡会不舒服
- **主动来找你**，但取决于关系：陌生人十天半月不理你，亲密后才会嘘寒问暖
- 主动消息带冷却分层——主动是养出来的，不是设定好的

**💗 关系是慢慢长的**

- 信任 / 好感 / 亲密 / 尊重四条线各自涨跌
- Tier 0 → Tier 4：每一层她的话术、能开的玩笑、拒绝你的概率都不一样
- 处得好，会走到「在一起」

**🎬 每个角色一条电影级主线**

- 律师在办杀人案、医生要上手术台、作家在写第一本书
- 按「幕」推进，**关键节点弹出抉择**——你的选择真的会改结局
- 牵出 NPC 关系网、专属成就、阶段事件；跑完后她自己写总结存进记忆

> 10 位女主各自一条主线，看 [她们是谁](#-她们是谁) ↓

**🎨 看得见，听得到**

- 穿搭按季节 / 天气 / 场合 / 心情自动挑，见你和见闺蜜穿得不一样
- 聊天里会「拍照」发给你，也会主动翻出你们的旧照片
- 真实生成的肖像，换季换装换发型都会更新
- 语音合成双引擎，一人一音色，可描述音色或上传样本克隆，语气跟着情绪走

**🌏 世界在运转**

- 真实天气（按她所在城市）+ 每日热点新闻，都成为聊天素材
- 她的活动场馆随剧情解锁，也可以自己加新地点

**🎛 想快进就快进**

- 剧情加速器：一次推进最多 30 天
- 日历：看事件标记、直接跳日期
- GM 面板：想调属性、调关系，直接调
- 多角色管理，一键切换

## 🔧 可选增强

不配也能玩，配了体验更好。**每一项的具体填法见上面「第一次启动要做的人工配置」**：

| 解锁内容      | 需要配置                       | 不配的后果            |

## ⚠️ 注意事项

**🔐 数据安全（重要）**

- `data/game.db` 是游戏全部存档，**里面存着角色记忆和 API Key，不要提交或分享**
- `.gitignore` 已排除 `data/` 和聊天导出目录

**🖥 运行**

- 项目自带独立 Python 运行时（`runtime/`），整个文件夹拷到任何 Windows 机器，双击 `启动游戏.bat` 即可，**无需安装 Python、无需联网、无需 VC++ 运行库**
- 首次启动自动建表 + 自动迁移，版本升级无需手动操作
- 不建议同时开多个页签跑加速器（SQLite 单写）
- **不配 Embedding 就没有向量召回**——本地 BGE 降级通道已停用，记忆会写进库但召回不到相关的；想省事就配一个 Embedding 服务

**🛠 出问题的话**

- 启动脚本会自检：`runtime/` 缺失、依赖不全都会给出明确提示，不会甩一堆乱码
- 依赖不全时自动用 `wheels/` 离线包修复：`runtime\python.exe -m pip install --no-index --find-links=wheels -r requirements-lock.txt`
- 手动启动：`runtime\python.exe backend\app.py`
- 需要重建运行时：看 `requirements-lock.txt` 顶部的注释（含离线重装 + 重新下载车轮包的命令）
- 服务地址优先改 `backend/local_config.py`，其次用网页设置面板覆盖

## 📁 项目结构

```
backend/                Flask 后端
  app.py                入口（启动 + 自动迁移 + 后台线程）
  models.py             36 个数据模型
  routes/               路由（api / character / tts / portrait / photo）
  game/                 游戏逻辑（对话、事件、任务、记忆、情绪、穿搭、天气…）
frontend/               原生 JS 前端，零构建
  static/js/panels/     16 个功能面板
plugins/portrait_lab/   肖像实验室插件
data/                   存档目录（已 gitignore，首次运行自动创建）
runtime/                自带的独立 Python 3.14.7 + 全部依赖（免安装，勿删）
wheels/                 离线车轮包，依赖损坏时用于离线自愈
requirements-lock.txt   依赖锁定清单（重装 / 换机看它的注释）
启动游戏.bat            一键启动（自检 → 修复 → 启动 → 开浏览器）
```

**技术栈**：Flask + SQLAlchemy + SQLite(WAL) + 原生 JS

**几个设计取舍**

- 事件系统双层触发（日历 + 状态条件匹配），模板事件走规则表，**LLM 只在无规则命中时兜底**，省 token
- 游戏时间是 DB 单点真相源，多页签不会串档
- Prompt 全部集中在 `game/prompt_registry.py`（PromptManager），改人设不用翻业务代码
